Example 3.7 (Continuous posets, [Johnstone and Joyal (1982); Gierz et al. (2003)]). Let \(P\) be a partially ordered set admitting directed joins, regarded as a category. Then \(\Ind (P)\) is the poset of ideals of \(P\), i.e. non-empty directed downward closed subsets \(I \subseteq P\), ordered by inclusion, and \(\colim \colon \Ind (P) \to P\) sends \(I\) to its join \(\bigvee I\). The functor \(y\) sends \(x\) to the principal ideal \({\downarrow }x\), which is the largest ideal with join \(\leq x\). A left adjoint \(\hat {y}\), if it exists, sends \(x\) to the smallest ideal \(I\) with \(x \leq \bigvee I\).

Say that \(y\) is way below \(x\), written \(y \ll x\), if \(y \in I\) for every ideal \(I\) with \(x \leq \bigvee I\); taking \(I = {\downarrow }x\) shows that \(y \ll x\) implies \(y \leq x\). Then \(\hat {y}\) exists if and only if for every \(x \in P\) the set \({\downarrow \!\!\downarrow }x = \{y \in P \mid y \ll x\}\) is directed with join \(x\), in which case \(\hat {y}(x) = {\downarrow \!\!\downarrow }x\); we prove this in Proposition 5.19. Posets with this property are classically called continuous. An element \(x\) is compact if and only if \(x \ll x\), in accordance with Lemma 3.2. For example:

(1)

In the interval \([0,1]\), we have \(y \ll x\) if and only if \(y < x\) or \(y = 0\). So \([0,1]\) is continuous, and its only compact element is \(0\).

(2)

Let \(X\) be a locally compact Hausdorff space and let \(\mathrm {Open}(X)\) be the poset of open subsets. Then \(U \ll V\) if and only if there exists a compact subset \(K \subseteq X\) with \(U \subseteq K \subseteq V\), and \(\mathrm {Open}(X)\) is continuous. The compact elements are the compact open subsets; for \(X = \R ^n\) the only one is \(\emptyset \).

(3)

The power set of a set \(S\) is continuous, and in fact algebraic, i.e. compactly generated: the compact elements are the finite subsets, and every subset is the directed union of its finite subsets.

Note how example (2) foreshadows the fact that \(\Shv (\R ^n;\Sp )\) is dualizable but has no nonzero compact objects. Continuous posets are discussed in more detail, with proofs, in Section 5.3.
