Continuous posets

← Previous chapterChapter 4 → Next chapterChapter 6 ← Previous sectionSection 5.2 → Next sectionSection 5.4

We now study a class of non-stable compactly assembled categories in detail, which was already briefly discussed in Example 3.7. They will reappear in Chapter 9, where we study sheaves on continuous posets. See [Gierz et al. (2003)] for a comprehensive treatment.

Throughout, let \(P\) be a partially ordered set, regarded as a category.

Lemma 5.14. The category \(\Ind (P)\) is (equivalent to) a partially ordered set. Explicitly, every object of \(\Ind (P)\) is of the form \(\quotcolim _{s \in S} s\) for a directed subset \(S \subseteq P\), and for directed subsets \(S,T \subseteq P\) we have \begin {align*} \Map _{\Ind (P)}\Big (\quotcolim _{s \in S} s, \quotcolim _{t \in T} t\Big ) &= \lim _{s \in S\catop }\colim _{t \in T}\Map _P(s,t) \\ &\simeq \begin {cases} * & \text {if for all } s \in S \text { there is } t \in T \text { with } s \leq t, \\ \emptyset & \text {otherwise.}\end {cases} \end {align*}

Hence \(\Ind (P)\) is equivalent to the poset of ideals of \(P\), i.e. non-empty, directed, downward closed subsets \(J \subseteq P\), ordered by inclusion, via \(S \mapsto {\downarrow }S := \{p \in P \mid p \leq s \text { for some } s \in S\}\).

Proof.

By Theorem A.8, every object of \(\Ind (P)\) is a colimit of representables indexed by a filtered poset \(I\), i.e. of the form \(\quotcolim _{i \in I} p_i\) for a functor \(p\colon I \to P\). The image \(S = p(I)\) is a directed subset, and the map \(I \to S\) is cofinal by Lemma A.7 (for \(s \in S\), the set \(\{i \mid s \leq p_i\}\) is non-empty and upward closed in the filtered poset \(I\), hence filtered). This proves the first claim. The formula for mapping spaces follows from Construction A.21: each \(\Map _P(s,t)\) is either empty or contractible, filtered colimits of such spaces are again empty or contractible (and contractible if and only if one of the terms is), and a limit of such spaces is contractible if and only if all terms are. In particular, all mapping spaces in \(\Ind (P)\) are empty or contractible, so \(\Ind (P)\) is a poset. Finally, the condition in the formula only depends on \({\downarrow }S\) and \({\downarrow }T\): it says precisely that \({\downarrow }S \subseteq {\downarrow }T\). □

Suppose now that \(P\) admits directed suprema. Then the colimit functor \(\colim \colon \Ind (P) \to P\) sends a directed subset \(S\) to \(\sup S\), and the Yoneda embedding sends \(b\) to \({\downarrow }b\).

Lemma 5.15. Let \(P\) be a small partially ordered set admitting directed suprema. Then \(P\) is accessible.

Proof.

Let \(\kappa \) be a regular cardinal with \(\kappa > |P|\). Let \(D \subseteq P\) be a \(\kappa \)-directed subset. Since \(|D| < \kappa \), the set \(D\) itself has an upper bound in \(D\) (Lemma A.5), i.e. \(D\) has a largest element. It follows that every \(\kappa \)-filtered diagram in \(P\) has a cofinal constant subdiagram, so that \(\kappa \)-filtered colimits in \(P\) are “trivial”: every object of \(P\) is \(\kappa \)-compact, and the Yoneda embedding \(P \to \Ind _{\kappa }(P)\) is an equivalence, as every \(\kappa \)-filtered colimit of representable presheaves on \(P\) is representable. Hence \(P \simeq \Ind _{\kappa }(P^{\kappa })\) is \(\kappa \)-accessible. □

Definition 5.16. A partially ordered set \(P\) is called continuous if it admits directed suprema and the functor \(\colim = \sup \colon \Ind (P) \to P\) admits a left adjoint \(\hat {y}\colon P \to \Ind (P)\).

By Lemma 5.15, a small poset is continuous if and only if it is compactly assembled. Unwinding the definitions using Lemma 5.14, the existence of the left adjoint \(\hat {y}\) means: for every \(b \in P\) there is a directed subset \(\hat {y}(b) \subseteq P\) such that for every directed subset \(T \subseteq P\), \begin {equation} \tag{5.1}\label {eq:Yhat_Poset} b \leq \sup T \iff \text {for all } s \in \hat {y}(b) \text { there exists } t \in T \text { with } s \leq t. \end {equation}

Definition 5.17. Let \(P\) be a poset admitting directed suprema, and let \(a,b \in P\). We say that \(a\) is way below \(b\), written \(a \ll b\), if for every directed subset \(T \subseteq P\) with \(b \leq \sup T\) there exists \(t \in T\) with \(a \leq t\). We write \[ P_{\ll b} := \{a \in P \mid a \ll b\}. \]

Remark 5.18.

(1)

If \(a \ll b\), then \(a \leq b\): apply the definition to \(T = \{b\}\).

(2)

If \(a' \leq a \ll b \leq b'\), then \(a' \ll b'\).

(3)

An element \(b\) is compact in \(P\) (i.e. \(\Map _P(b,-)\) preserves filtered colimits) if and only if \(b \ll b\).

(4)

If \(P\) is continuous, then \(\hat {y}(b) \subseteq P_{\ll b}\) for every \(b\). Indeed, let \(s \in \hat {y}(b)\) and let \(T\) be directed with \(b \leq \sup T\). By (5.1), there exists \(t \in T\) with \(s \leq t\), so \(s \ll b\).

Proposition 5.19. Let \(P\) be a poset admitting directed suprema. Then \(P\) is continuous if and only if for every \(b \in P\) the subset \(P_{\ll b}\) is directed and \(\sup P_{\ll b} = b\). In this case, \(\hat {y}(b) = P_{\ll b}\), viewed as an object of \(\Ind (P)\).

Proof.

Suppose that each \(P_{\ll b}\) is directed with supremum \(b\). We claim that \(b \mapsto P_{\ll b}\) satisfies (5.1), and hence defines a left adjoint to \(\sup \) (a monotone map, by Remark 5.18(2)). If \(b \leq \sup T\), then by definition every \(a \ll b\) satisfies \(a \leq t\) for some \(t \in T\). Conversely, if every \(a \in P_{\ll b}\) is bounded by some element of \(T\), then \(b = \sup P_{\ll b} \leq \sup T\).

Conversely, suppose that \(P\) is continuous. We claim that \[ P_{\ll b} = \{a \in P \mid a \leq s \text { for some } s \in \hat {y}(b)\} = {\downarrow }\hat {y}(b). \] For “\(\supseteq \)”, note that \(\hat {y}(b) \subseteq P_{\ll b}\) by Remark 5.18(4), and \(P_{\ll b}\) is downward closed by Remark 5.18(2). For “\(\subseteq \)”, note that \(\hat {y}\) is fully faithful (Lemma A.26), so the counit \(\sup \hat {y}(b) \leq b\) is an equality, i.e. \(b = \sup \hat {y}(b)\). Applying the definition of \(a \ll b\) to the directed set \(T = \hat {y}(b)\) gives \(s \in \hat {y}(b)\) with \(a \leq s\). Since \(\hat {y}(b)\) is directed, so is \({\downarrow }\hat {y}(b) = P_{\ll b}\), and \(\sup P_{\ll b} = \sup \hat {y}(b) = b\). Finally, \(P_{\ll b}\) and \(\hat {y}(b)\) define the same object of \(\Ind (P)\) by Lemma 5.14. □

Example 5.20. The poset \(P = \R \cup \{\infty \}\) (with its usual order) admits directed suprema: the supremum of a non-empty subset is its usual supremum if the subset is bounded, and \(\infty \) otherwise. We claim that \(a \ll b\) if and only if \(a < b\). If \(a < b\) and \(T\) is directed with \(b \leq \sup T\), then \(\sup T > a\), so some \(t \in T\) satisfies \(t > a\). Conversely, suppose \(a \ll b\); then \(a \leq b\) by Remark 5.18(1). If \(a = b\), consider the directed set \(T = \{b - 1/n \mid n \geq 1\}\) (for \(b \in \R \)) resp. \(T = \N \) (for \(b = \infty \)): it has supremum \(b\), but no element \(t \in T\) satisfies \(b \leq t\). Hence \(a < b\). It follows that \(P_{\ll b} = \{a \mid a < b\}\) is directed with supremum \(b\), so \(P\) is continuous by Proposition 5.19, with \(\hat {y}(b) = \quotcolim _{a < b} a\). Note that \(P\) has no compact elements.

Example 5.21. Let \(X\) be a locally compact Hausdorff space and let \(\Open (X)\) be the poset of open subsets of \(X\), ordered by inclusion. Directed suprema in \(\Open (X)\) are unions. We claim that \[ U \ll V \iff \overline {U} \text { is compact and } \overline {U} \subseteq V, \] in which case we write \(U \Subset V\). Suppose first that \(\overline {U}\) is compact and \(\overline {U} \subseteq V\), and let \((W_i)_{i \in I}\) be a directed family of open subsets with \(V \subseteq \bigcup _i W_i\). Then the \(W_i\) cover the compact set \(\overline {U}\), so finitely many of them do, and since the family is directed, a single \(W_i\) contains \(\overline {U} \supseteq U\). Conversely, let \(U \ll V\). Since \(X\) is locally compact Hausdorff, every point \(x \in V\) has an open neighbourhood \(W\) with \(\overline {W}\) compact and \(\overline {W} \subseteq V\). Hence \(V\) is the union of the family \(\{W \in \Open (X) \mid W \Subset V\}\), which is directed since \(W_1 \cup W_2 \Subset V\) if \(W_1,W_2 \Subset V\). By assumption, \(U \subseteq W\) for some \(W \Subset V\), and then \(\overline {U} \subseteq \overline {W}\) is a closed subset of a compact set, hence compact, and \(\overline {U} \subseteq \overline {W} \subseteq V\).

The argument shows moreover that \(\Open (X)_{\ll V}\) is directed with union \(V\), so \(\Open (X)\) is a continuous poset by Proposition 5.19, with \(\hat {y}(V) = \quotcolim _{U \Subset V} U\). Its compact elements are the open subsets \(U\) with \(U \Subset U\), i.e. the compact open subsets of \(X\).

Remark 5.22. If \(X\) is a locally compact Hausdorff space, then the morphism \(h_U \to h_V\) of representable sheaves on \(X\) is a compact morphism in \(\Shv (X;\Sp )\) whenever \(U \Subset V\) (Mathew, Lecture 3). Since every open \(V\) is the union of a sequence \(U_0 \Subset U_1 \Subset \cdots \) if \(X\) is second countable, this suggests (and, suitably generalized, proves) that \(\Shv (X;\Sp )\) is generated by sequential colimits along compact morphisms and hence dualizable, cf. Remark 3.21. We will return to this in Chapter 9.
