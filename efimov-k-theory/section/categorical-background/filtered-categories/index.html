Filtered and κ-filtered categories

← Previous chapterChapter 7 ← Previous sectionSection 7.4 → Next sectionSection A.2

Filtered colimits are the basic tool throughout these notes: compactness, Ind-categories and accessibility are all defined in terms of them. We recall the relevant definitions, and prove some technical results on \(\kappa \)-filtered partially ordered sets and sequential diagrams, which are used in the study of \(\omega _1\)-presentability in Section 3.4.

Definition A.1. We use the quasicategory model to specify the size of diagram shapes: a simplicial set is \(\kappa \)-small if it has fewer than \(\kappa \) nondegenerate simplices. A category \(I\) is \(\kappa \)-filtered if every diagram \(K\to I\) indexed by a \(\kappa \)-small simplicial set extends to a cocone \(K^{\triangleright }\to I\). This property is independent of the chosen model of \(I\). The phrases \(\kappa \)-small limit and \(\kappa \)-small colimit likewise refer to these diagram shapes. We say filtered for \(\omega \)-filtered. A colimit indexed by a small \(\kappa \)-filtered category is called a \(\kappa \)-filtered colimit.

Definition A.2. Let \(C\) be a category which admits \(\kappa \)-filtered colimits. An object \(x \in C\) is called \(\kappa \)-compact if the functor \(\Map _C(x,-)\colon C \to \An \) preserves \(\kappa \)-filtered colimits. We write \(C^{\kappa } \subseteq C\) for the full subcategory of \(\kappa \)-compact objects, and say compact for \(\omega \)-compact.

We will freely use the following fundamental fact.

Theorem A.3 ([Lurie (2009), Proposition 5.3.3.3]). In \(\An \), \(\kappa \)-filtered colimits commute with \(\kappa \)-small limits. For \(\kappa =\omega \), preservation of finite limits by \(\colim _I\) also characterizes filtered indexing categories \(I\), see [SHT, Theorem 22.6.3].

Corollary A.4. Let \(C\) be a category with \(\kappa \)-filtered colimits.

(1)

If \(\kappa \leq \lambda \), then every \(\kappa \)-compact object of \(C\) is \(\lambda \)-compact.

(2)

If \(C\) admits \(\kappa \)-small colimits, then \(C^{\kappa } \subseteq C\) is closed under \(\kappa \)-small colimits.

(3)

Let \(x \in C\) and let \(u\colon \Map _C(x,-) \to \Map _C(x',-)\) exhibit \(\Map _C(x,-)\) as a retract of \(\Map _C(x',-)\) in \(\Fun (C,\An )\). If \(x'\) is \(\kappa \)-compact, then so is \(x\). In particular, \(C^{\kappa }\) is closed under retracts.

Proof.

(1) A \(\lambda \)-filtered category is \(\kappa \)-filtered.

(2) If \(x = \colim _{k \in K} x_k\) with \(K\) \(\kappa \)-small and each \(x_k\) \(\kappa \)-compact, then \(\Map _C(x,-) = \lim _{k \in K\catop } \Map _C(x_k,-)\) is a \(\kappa \)-small limit of functors preserving \(\kappa \)-filtered colimits, hence preserves \(\kappa \)-filtered colimits by Theorem A.3.

(3) A retract of a functor preserving \(\kappa \)-filtered colimits again preserves them, since a retract of an equivalence in \(\An \) (namely the comparison map from the colimit) is an equivalence. □

For partially ordered sets, \(\kappa \)-filteredness admits the expected elementary description.

Lemma A.5. A partially ordered set \(P\) is \(\kappa \)-filtered if and only if every subset \(S \subseteq P\) of cardinality \(< \kappa \) admits an upper bound in \(P\). In particular, \(P\) is filtered if and only if it is non-empty and every two elements admit a common upper bound.

Proof.

Suppose \(P\) is \(\kappa \)-filtered and let \(S \subseteq P\) have cardinality \(< \kappa \). Regarding \(S\) as a discrete category, the inclusion \(S \to P\) is a \(\kappa \)-small diagram, and a cocone on it is precisely an upper bound of \(S\).

Conversely, let \(F\colon K \to P\) be a functor with \(K\) \(\kappa \)-small. Then \(K\) has fewer than \(\kappa \) objects up to equivalence, so the image \(S\) of \(F\) on objects has cardinality \(< \kappa \). Choose an upper bound \(u\) of \(S\). Since \(\Fun (K,P)\) is again a partially ordered set, in which \(F \leq G\) if and only if \(F(k) \leq G(k)\) for all \(k\), there is a (unique) natural transformation from \(F\) to the constant functor with value \(u\), i.e. a cocone on \(F\).

For the last statement, note that every finite subset of \(P\) has an upper bound if and only if \(P\) is non-empty and every two elements have an upper bound, by induction on the size of the subset. □

Lemma A.6. A filtered partially ordered set \(P\) is \(\omega _1\)-filtered if and only if every increasing sequence \(p_0 \leq p_1 \leq p_2 \leq \dots \) in \(P\) admits an upper bound.

Proof.

The condition is clearly necessary. Conversely, let \(S = \{s_0,s_1,s_2,\dots \} \subseteq P\) be a countable subset (a finite subset has an upper bound since \(P\) is filtered). Using that \(P\) is filtered, choose inductively \(p_0 \geq s_0\) and \(p_n \geq p_{n-1}, s_n\) for \(n \geq 1\). Then an upper bound for the increasing sequence \((p_n)_n\) is an upper bound for \(S\). We conclude by Lemma A.5. □

We will often use the following criterion for cofinality, see [Lurie (2009), Theorem 4.1.3.1]: a functor \(f\colon A \to B\) is cofinal if and only if for every \(b \in B\) the category \(A \times _B B_{b/}\) is weakly contractible. If \(A\) and \(B\) are partially ordered sets, then \(A \times _B B_{b/}\) is the partially ordered set \(\{a \in A \mid b \leq f(a)\}\). Since filtered categories are weakly contractible [Lurie (2009), Lemma 5.3.1.20], we obtain:

Lemma A.7. Let \(f\colon A \to B\) be a map of partially ordered sets such that for every \(b \in B\) the subset \(\{a \in A \mid b \leq f(a)\} \subseteq A\) is non-empty and filtered. Then \(f\) is cofinal. In particular:

(1)

A map \(f\colon \N \to B\) into a partially ordered set is cofinal if for every \(b \in B\) there exists \(n\) with \(b \leq f(n)\).

(2)

Every countable filtered partially ordered set \(Q\) admits a cofinal map \(\N \to Q\).

(3)

The diagonal \(\N \to \N \times \N \) is cofinal, and so is every map \(f\colon \N \to \N \) with \(f(n) \geq n\) for all \(n\).

Proof.

The first statement was explained above. For (1), the subset \(\{n \mid b \leq f(n)\}\) is non-empty and upwards closed in \(\N \) (as \(f\) is order preserving), hence of the form \(\{n \geq n_0\}\), which is filtered. For (2), if \(Q\) is finite it has a largest element (Lemma A.5) and we may take the constant map. Otherwise enumerate \(Q = \{q_0,q_1,\dots \}\) and choose inductively \(f(0) = q_0\) and \(f(n) \geq f(n-1), q_n\); then \(f\) is order preserving and cofinal by (1). Statement (3) follows directly from (1). □

Theorem A.8 ([Lurie (2009), Proposition 5.3.1.18]). For every \(\kappa \)-filtered category \(I\) there exist a \(\kappa \)-filtered partially ordered set \(P\) and a cofinal functor \(P \to I\).

Proposition A.9. Let \(P\) be a filtered partially ordered set, and let \(\Sigma \) be the set of countable filtered subsets \(Q \subseteq P\), ordered by inclusion. Then \(\Sigma \) is \(\omega _1\)-filtered and \(P = \bigcup _{Q \in \Sigma } Q\). Moreover, for every functor \(F\colon P \to D\) into a category with filtered colimits, there is a natural equivalence \[ \colim _{p \in P} F(p) \simeq \colim _{Q \in \Sigma } \colim _{q \in Q} F(q). \]

Proof.

Every \(p \in P\) lies in the countable filtered subset \(\{p\}\). Let \(Q_0,Q_1,\dots \in \Sigma \) be countably many elements. Put \(U_0 = \bigcup _n Q_n\) (and add one element of \(P\) if the family is empty), and inductively let \(U_{k+1} \supseteq U_k\) be obtained by adding a chosen common upper bound in \(P\) for every pair of elements of \(U_k\). Then \(U = \bigcup _k U_k\) is countable, and any two elements of \(U\) have an upper bound in \(U\); hence \(U \in \Sigma \) by Lemma A.5, and \(U\) is an upper bound of the \(Q_n\). So \(\Sigma \) is \(\omega _1\)-filtered by Lemma A.5.

Consider the partially ordered set \(E = \{(Q,q) \mid Q \in \Sigma , q \in Q\}\), with \((Q,q) \leq (Q',q')\) if \(Q \subseteq Q'\) and \(q \leq q'\), together with the projections \(\pi \colon E \to \Sigma \) and \(\rho \colon E \to P\). The map \(\rho \) is cofinal by Lemma A.7: for \(p \in P\), the subset \(\{(Q,q) \mid p \leq q\}\) is non-empty, and it is filtered since two elements \((Q,q),(Q',q')\) are bounded by \((Q'',q'')\) where \(q''\) is an upper bound of \(q,q'\) and \(Q'' \in \Sigma \) contains \(Q \cup Q' \cup \{q''\}\). Hence \(\colim _P F \simeq \colim _E F\rho \simeq \colim _{\Sigma } \pi _!(F\rho )\), where \(\pi _!\) denotes left Kan extension along \(\pi \). All indexing categories in this calculation are filtered, so the assumed filtered colimits suffice. For \(Q \in \Sigma \) we have \(\pi _!(F\rho )(Q) = \colim _{(Q',q') \in E,\, Q' \subseteq Q} F(q')\), and the map \(Q \to \{(Q',q') \in E \mid Q' \subseteq Q\}\), \(q \mapsto (Q,q)\), is cofinal by Lemma A.7: for \((Q',q')\) with \(Q' \subseteq Q\), the subset \(\{q \in Q \mid q' \leq q\}\) is non-empty and filtered. Hence \(\pi _!(F\rho )(Q) \simeq \colim _{q \in Q} F(q)\), which proves the claim. □

Remark A.10. Since the nerve of \(\N \) contains the simplicial subset \(\bigcup _n \Delta ^{\{n,n+1\}}\) via an inner anodyne map, a functor \(\N \to D\) amounts to a sequence of objects and morphisms \(x_0 \to x_1 \to x_2 \to \dots \) in \(D\), without further coherence data. Similarly, since \(\Delta ^1 \times \bigcup _n \Delta ^{\{n,n+1\}} \subseteq \Delta ^1 \times \N \) is inner anodyne [Lurie (2009), Corollary 2.3.2.4], a natural transformation \(\eta \colon x_{\bullet } \to x'_{\bullet }\) of sequences amounts to morphisms \(\eta _n\colon x_n \to x'_n\) together with homotopies witnessing the commutativity of each square We will use this freely.

Lemma A.11 (Telescopes). Let \(D\) be a category with sequential colimits, and let \(X \xrightarrow {s} Y \xrightarrow {r} X\) be maps with \(rs \simeq \id _X\). Then \(X \simeq \colim (Y \xrightarrow {e} Y \xrightarrow {e} Y \to \dots )\), where \(e = sr\). The same telescope computes \(X\) even if \(D\) does not admit arbitrary sequential colimits, see [SCT, Lemma 17.4.3].

Proof.

Consider the sequence \(Y \xrightarrow {r} X \xrightarrow {s} Y \xrightarrow {r} X \xrightarrow {s} \dots \). The maps \(\N \to \N \) given by \(n \mapsto 2n\) and \(n \mapsto 2n+1\) are cofinal by Lemma A.7. Restricting along the first gives the sequence \(Y \xrightarrow {e} Y \xrightarrow {e} \dots \), and restricting along the second gives a sequence \(X \to X \to \dots \) all of whose maps are equivalences \(rs \simeq \id _X\); the colimit of the latter is \(X\). Hence both colimits agree with the colimit of the interleaved sequence. □

We now describe the \(\omega _1\)-compact objects of \(\Ind (C)\). Recall that for a small category \(C\), the category \(\Ind (C) \subseteq \PSh (C)\) is the full subcategory spanned by the filtered colimits of representable presheaves. It admits filtered colimits, computed in \(\PSh (C)\), and the representable presheaves are compact in \(\Ind (C)\) [Lurie (2009), Section 5.3.5]. We usually suppress the Yoneda embedding \(y\) when no confusion can arise, and write \(\quotcolim _i c_i\) for the colimit in \(\Ind (C)\) of a diagram of representables when we want to stress that it is a formal colimit.

Lemma A.12 (Strictification of maps between sequential ind-objects). Let \(C\) be a small category, let \(a_{\bullet }, b_{\bullet }\colon \N \to C\) be sequences, and put \(Y = \colim _n y(a_n)\) and \(Z = \colim _n y(b_n)\) in \(\Ind (C)\). For every map \(g\colon Y \to Z\) there exist a strictly increasing map \(f\colon \N \to \N \) with \(f(n) \geq n\) and a natural transformation \(\eta \colon a_{\bullet } \to b_{f(\bullet )}\) of functors \(\N \to C\) such that the induced map \[ Y = \colim _n y(a_n) \xrightarrow {\colim \eta } \colim _n y(b_{f(n)}) \simeq Z \] is homotopic to \(g\). Here the last equivalence comes from cofinality of \(f\) (Lemma A.7).

Proof.

Denote by \(\alpha _n\colon a_n \to a_{n+1}\) and \(\beta _{m,m'}\colon b_m \to b_{m'}\) the transition maps, and by \(\iota _m\colon b_m \to Z\) the canonical maps. Since \(\Map (Y,Z) \simeq \lim _n \Map (a_n,Z)\), the map \(g\) amounts to maps \(g_n\colon a_n \to Z\) together with paths \(\gamma _n\colon g_{n+1}\alpha _n \simeq g_n\) in \(\Map (a_n,Z)\). Since \(a_n\) is compact in \(\Ind (C)\), we have \(\Map (a_n,Z) \simeq \colim _m \Map (a_n,b_m)\). By Theorem A.3, path spaces in this filtered colimit are computed as filtered colimits of path spaces; in particular every point and every path in \(\Map (a_n,Z)\) between images of points of \(\Map (a_n,b_m)\) lifts, up to homotopy, to some stage \(m' \geq m\).

By Remark A.10, the data of \(f\) and \(\eta \) amount to maps \(\eta _n\colon a_n \to b_{f(n)}\) and homotopies \(\theta _n\colon \eta _{n+1}\alpha _n \simeq \beta _{f(n),f(n+1)}\eta _n\). The induced map \(\colim \eta \) corresponds to the point \((\iota _{f(n)}\eta _n)_n\) of \(\lim _n \Map (a_n,Z)\), with the paths \(\iota _{f(n+1)}\eta _{n+1}\alpha _n \simeq \iota _{f(n+1)}\beta _{f(n),f(n+1)}\eta _n \simeq \iota _{f(n)}\eta _n\) induced by \(\theta _n\). To exhibit a homotopy \(\colim \eta \simeq g\), it therefore suffices to choose paths \(\sigma _n\colon \iota _{f(n)}\eta _n \simeq g_n\) in \(\Map (a_n,Z)\) such that for each \(n\) the two resulting paths from \(\iota _{f(n+1)}\eta _{n+1}\alpha _n\) to \(g_n\), namely \(\sigma _n \circ \iota \theta _n\) and \(\gamma _n \circ \sigma _{n+1}\alpha _n\), are homotopic.

We construct these data inductively. First choose \(f(0)\), \(\eta _0\colon a_0 \to b_{f(0)}\) and \(\sigma _0\colon \iota _{f(0)}\eta _0 \simeq g_0\). Suppose \(f(0),\dots ,f(n)\), \(\eta _0,\dots ,\eta _n\), \(\theta _0,\dots ,\theta _{n-1}\) and \(\sigma _0,\dots ,\sigma _n\) have been constructed. Choose \(m > f(n)\), a map \(\eta '\colon a_{n+1} \to b_m\) and a path \(\sigma '\colon \iota _m\eta ' \simeq g_{n+1}\). The maps \(\eta '\alpha _n\) and \(\beta _{f(n),m}\eta _n\) in \(\Map (a_n,b_m)\) have images in \(\Map (a_n,Z)\) connected by the path \[ \iota _m\eta '\alpha _n \overset {\sigma '\alpha _n}{\simeq } g_{n+1}\alpha _n \overset {\gamma _n}{\simeq } g_n \overset {\sigma _n^{-1}}{\simeq } \iota _{f(n)}\eta _n. \] Hence there exist \(m' \geq m\) and a path \(\theta \) from \(\beta _{m,m'}\eta '\alpha _n\) to \(\beta _{f(n),m'}\eta _n\) in \(\Map (a_n,b_{m'})\) whose image in \(\Map (a_n,Z)\) is homotopic to this path. Put \(f(n+1) = \max (m',n+1)\), \(\eta _{n+1} = \beta _{m,f(n+1)}\eta '\), let \(\theta _n\) be the image of \(\theta \), and let \(\sigma _{n+1}\) be the path \(\iota _{f(n+1)}\eta _{n+1} \simeq \iota _m\eta ' \overset {\sigma '}{\simeq } g_{n+1}\). By construction, the compatibility condition above holds. This completes the induction. □

Proposition A.13. Let \(C\) be a small category and let \(X \in \Ind (C)\). Then \(X\) is \(\omega _1\)-compact if and only if \(X \simeq \colim _n y(c_n)\) for some sequence \(c_0 \to c_1 \to c_2 \to \dots \) in \(C\).

Proof.

If \(X\) is a sequential colimit of representables, then \(X\) is a countable colimit of compact objects, hence \(\omega _1\)-compact by Corollary A.4.

Conversely, let \(X\) be \(\omega _1\)-compact. By definition of \(\Ind (C)\) and Theorem A.8, we may write \(X = \colim _{p \in P} y(c_p)\) for a filtered partially ordered set \(P\). By Proposition A.9, we have \(X \simeq \colim _{Q \in \Sigma } X_Q\) with \(X_Q = \colim _{q \in Q} y(c_q)\) and \(\Sigma \) \(\omega _1\)-filtered. As \(X\) is \(\omega _1\)-compact, \(\Map (X,X) \simeq \colim _{Q} \Map (X,X_Q)\), so the identity of \(X\) factors as \(X \xrightarrow {s} X_Q \xrightarrow {r} X\) for some \(Q \in \Sigma \). By Lemma A.7(2), \(X_Q\) is a sequential colimit \(Y = \colim _n y(a_n)\) of representables. By Lemma A.11, \(X \simeq \colim (Y \xrightarrow {e} Y \xrightarrow {e} \dots )\) with \(e = sr\).

By Lemma A.12, there exist \(f\colon \N \to \N \) with \(f(n) \geq n\) and a natural transformation \(\eta \colon a_{\bullet } \to a_{f(\bullet )}\) inducing \(e\) on colimits. Define a functor \(\Phi \colon \N \times \N \to C\) by \(\Phi (k,n) = a_{f^k(n)}\), with horizontal maps the transition maps of \(a_{\bullet }\) and vertical maps \(\eta _{f^k(n)}\colon a_{f^k(n)} \to a_{f^{k+1}(n)}\); by Remark A.10 this is the functor \(\N \to \Fun (\N ,C)\) given by the sequence \(a_{\bullet } \to a_{f(\bullet )} \to a_{f^2(\bullet )} \to \dots \) of whiskerings of \(\eta \). Since each \(f^k\) is cofinal, \(\colim _n y\Phi (k,n) \simeq Y\), and under these identifications the induced map in the \(k\)-direction is \(\colim \eta \simeq e\). Hence \[ X \simeq \colim _k \colim _n y\Phi (k,n) \simeq \colim _{(k,n) \in \N \times \N } y\Phi (k,n) \simeq \colim _n y\Phi (n,n), \] where the last equivalence uses cofinality of the diagonal (Lemma A.7(3)). So \(X\) is a sequential colimit of representables. □
