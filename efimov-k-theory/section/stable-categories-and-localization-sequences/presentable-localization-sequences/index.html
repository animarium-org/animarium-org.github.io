Localization sequences of presentable stable categories

← Previous chapterChapter 1 → Next chapterChapter 3 ← Previous sectionSection 2.2 → Next sectionSection 2.4

We now turn to large categories. Recall that \(\PrL _{\st }\) denotes the category of presentable stable categories and colimit-preserving functors. A colimit-preserving functor \(F\colon D \to E\) between presentable categories has a right adjoint \(F^R\) (Theorem A.19); recall that \(F\) is called strongly continuous if \(F^R\) again preserves colimits. We denote by \(\Pr ^{\mathrm {LL}}_{\st } \subseteq \PrL _{\st }\) the subcategory with the same objects and strongly continuous functors.

Definition 2.11. A sequence \(K \xrightarrow {i} D \xrightarrow {p} E\) in \(\PrL _{\st }\) with \(pi \simeq 0\) is called a localization sequence if \(i\) is fully faithful with essential image \(\ker (p)\) and \(p\) is a localization, i.e. its right adjoint \(p^R\) is fully faithful. It is called strongly continuous if moreover \(i\) and \(p\) are strongly continuous.

For a full subcategory \(K \subseteq D\) we write \(K^{\perp } = \{x \in D \mid \Map _D(k,x) \simeq * \text { for all } k \in K\}\) for its right orthogonal.

Proposition 2.12.

(1)

Let \(D\) be a presentable stable category and \(K \subseteq D\) a full stable subcategory which is closed under colimits and presentable. Then the inclusion \(i\colon K \hookrightarrow D\) has a right adjoint \(i^R\), the full subcategory \(K^{\perp } \subseteq D\) is presentable, its inclusion admits a left adjoint \(L\colon D \to K^{\perp }\) given by \[ L(x) = \cofib (ii^R x \to x), \] and \(K \xrightarrow {i} D \xrightarrow {L} K^{\perp }\) is a localization sequence. It is both a fiber sequence and a cofiber sequence in \(\PrL _{\st }\).

(2)

Conversely, let \(K \xrightarrow {i} D \xrightarrow {p} E\) be a localization sequence. Then \(p^R\) induces an equivalence \(E \simeq K^{\perp }\) under which \(p\) corresponds to \(L\), and there is a natural cofiber sequence \[ ii^R \to \id _D \to p^Rp. \]

Proof.

(1) The inclusion \(i\) preserves colimits, so it has a right adjoint by Theorem A.19. Define \(L(x) = \cofib (ii^Rx \to x)\), using the counit. For \(k \in K\), the map \(\hom _D(k,ii^Rx) \to \hom _D(k,x)\) is an equivalence since \(i\) is fully faithful, so \(\hom _D(k,L(x)) \simeq 0\); that is, \(L(x) \in K^{\perp }\). For \(y \in K^{\perp }\), applying \(\hom _D(-,y)\) to the cofiber sequence \(ii^Rx \to x \to L(x)\) shows that \(\hom _D(L(x),y) \to \hom _D(x,y)\) is an equivalence, since \(\hom _D(ii^Rx,y) \simeq 0\). Hence \(L\colon D \to K^{\perp }\) is left adjoint to the inclusion \(K^{\perp } \subseteq D\), with unit \(x \to L(x)\). The functor \(L\) is accessible since \(i^R\) is (being a right adjoint between presentable categories), so \(K^{\perp }\) is presentable [Lurie (2009), Section 5.5.4]. Since its right adjoint is fully faithful, \(L\) is a localization, and \(L(x) \simeq 0\) if and only if \(ii^Rx \to x\) is an equivalence, if and only if \(x \in K\). This shows that \(K \to D \to K^{\perp }\) is a localization sequence. It is a fiber sequence in \(\PrL _{\st }\) since limits in \(\PrL \) are computed in \(\widehat {\Cat }\). For the cofiber sequence, let \(F\colon D \to E\) be a colimit-preserving functor to a presentable stable category \(E\). Since \(L\) is a localization, restriction along \(L\) identifies \(\Fun ^{\colim }(K^{\perp },E)\) with the full subcategory of \(\Fun ^{\colim }(D,E)\) of functors inverting the maps \(x \to x'\) with \(L(x) \simeq L(x')\). Since \(L\) is exact, these are precisely the maps whose fiber lies in \(\ker (L) = K\), and an exact functor inverts all such maps if and only if it vanishes on \(K\). This is precisely the universal property of the cofiber of \(i\) in \(\PrL _{\st }\).

(2) Since \(p^R\) is fully faithful and \(\Map _D(k,p^Re) \simeq \Map _E(pk,e) \simeq *\) for \(k \in K\), the functor \(p^R\) lands in \(K^{\perp }\). Conversely, let \(x \in K^{\perp }\) and let \(f \to x \to p^Rp(x)\) be the fiber sequence of the unit. As \(pp^R \simeq \id \), we have \(p(f) \simeq 0\), so \(f \in K\). Then \(\hom _D(f,x) \simeq 0\) and \(\hom _D(f,p^Rpx) \simeq \hom _E(pf,px) \simeq 0\), so \(\hom _D(f,f) \simeq 0\) and hence \(f \simeq 0\). So \(x \simeq p^Rp(x)\), which shows that \(p^R\) induces an equivalence \(E \simeq K^{\perp }\). Under this equivalence, \(p\) is identified with the left adjoint \(L\) of the inclusion \(K^{\perp } \subseteq D\), and the unit \(x \to p^Rp(x) = L(x)\) is the cofiber of \(ii^Rx \to x\) by (1). □

Lemma 2.13. Let \(K \xrightarrow {i} D \xrightarrow {p} E\) be a localization sequence. Then \(i^R\) preserves colimits if and only if \(p^R\) preserves colimits. In particular, the sequence is strongly continuous as soon as \(i\) or \(p\) is strongly continuous.

Proof.

Since \(i\) is fully faithful and preserves colimits, \(i^R\) preserves colimits if and only if \(ii^R\) does: indeed, for a diagram \((x_j)\) the map \(i(\colim _j i^Rx_j) \simeq \colim _j ii^Rx_j \to ii^R(\colim _j x_j)\) is the image under \(i\) of the comparison map for \(i^R\). Similarly, \(p^R\) preserves colimits if and only if \(p^Rp\) does: if \(p^Rp\) preserves colimits and \((e_j)\) is a diagram in \(E\), then \(\colim _j e_j \simeq p(\colim _j p^Re_j)\), so \(p^R(\colim _j e_j) \simeq p^Rp(\colim _j p^Re_j) \simeq \colim _j p^Rpp^Re_j \simeq \colim _j p^Re_j\). Finally, by Proposition 2.12(2) there is a cofiber sequence of exact functors \(ii^R \to \id \to p^Rp\), so \(ii^R\) preserves colimits if and only if \(p^Rp\) does. □

Recall that a presentable stable category \(E\) is compactly generated if \(E \simeq \Ind (E^{\omega })\), equivalently if there is a set \(G\) of compact objects of \(E\) such that an object \(e \in E\) with \(\hom _E(g,e) \simeq 0\) for all \(g \in G\) is zero.

Lemma 2.14. Let \(E\) be a presentable stable category and \(G \subseteq E^{\omega }\) a set of compact objects such that \(\hom _E(g,e) \simeq 0\) for all \(g \in G\) implies \(e \simeq 0\). Then \(E^{\omega }\) is the thick closure of \(G\), and \(E \simeq \Ind (E^{\omega })\).

Proof.

Let \(T \subseteq E^{\omega }\) be the thick closure of \(G\); it is essentially small. The functor \(\Ind (T) \to E\) extending the inclusion is fully faithful since \(T\) consists of compact objects, and its essential image is closed under colimits since \(T\) is closed under finite colimits [Lurie (2009), Section 5.3.5]. Its right adjoint is conservative: if \(\hom _E(t,e) \simeq 0\) for all \(t \in T\) then \(e \simeq 0\) by assumption. Hence \(\Ind (T) \simeq E\). Since \(T\) is idempotent complete, the compact objects of \(\Ind (T)\) are precisely the objects of \(T\) (Theorem A.17(1)), so \(E^{\omega } = T\). □

Lemma 2.15. Let \(K \xrightarrow {i} D \xrightarrow {p} E\) be a strongly continuous localization sequence. Then \(i\) and \(p\) preserve compact objects, and \(K^{\omega } = K \cap D^{\omega }\). If \(D\) is compactly generated, then so is \(E\), and \(E^{\omega }\) is the thick closure of \(p(D^{\omega })\).

Proof.

A colimit-preserving functor whose right adjoint preserves filtered colimits preserves compact objects. If \(k \in K\) is compact in \(D\), then it is compact in \(K\) since \(i\) is fully faithful and preserves colimits. If \(D\) is compactly generated and \(e \in E\) satisfies \(\hom _E(p(d),e) \simeq \hom _D(d,p^Re) \simeq 0\) for all \(d \in D^{\omega }\), then \(p^Re \simeq 0\) and hence \(e \simeq pp^Re \simeq 0\). The claim follows from Lemma 2.14. □

Definition 2.16 ([Efimov (2024), Definition 1.9]). A functor \(f\colon A \to B\) in \(\Cat _{\perf }\) is called a homological epimorphism if \(\Ind (f)\colon \Ind (A) \to \Ind (B)\) is a localization, i.e. its right adjoint is fully faithful.

Theorem 2.17 (Thomason–Neeman).

(1)

If \(A \xrightarrow {i} B \xrightarrow {p} C\) is a short exact sequence in \(\Cat _{\perf }\), then \(\Ind (A) \to \Ind (B) \to \Ind (C)\) is a strongly continuous localization sequence. In particular, every Karoubi projection is a homological epimorphism.

(2)

Conversely, if \(K \xrightarrow {i} D \xrightarrow {p} E\) is a strongly continuous localization sequence in which \(K\) and \(D\) are compactly generated, then \(E\) is compactly generated and \(K^{\omega } \to D^{\omega } \to E^{\omega }\) is a short exact sequence.

Proof.

(1) The functor \(\Ind (i)\) is fully faithful, as mapping spaces between ind-objects are computed by the formula of Construction A.21. Its essential image \(K \subseteq \Ind (B)\) is closed under colimits and presentable, so by Proposition 2.12(1) we obtain a localization sequence \(K \to \Ind (B) \xrightarrow {L} K^{\perp }\) which is a cofiber sequence in \(\PrL _{\st }\). For every presentable stable category \(E\), we have natural equivalences \[ \begin {aligned} \Fun ^{\colim }(K^{\perp },E) &\simeq \Fun ^{\colim }_{K \mapsto 0}(\Ind (B),E) \simeq \Fun ^{\ex }_{A \mapsto 0}(B,E) \\ &\simeq \Fun ^{\ex }(B/A,E) \simeq \Fun ^{\ex }((B/A)^{\idem },E) \simeq \Fun ^{\colim }(\Ind (C),E), \end {aligned} \] using Theorem A.15(3), Theorem 2.1(2), the fact that \(E\) is idempotent complete, and \((B/A)^{\idem } \simeq C\). Under these equivalences, precomposition with \(L\) corresponds to precomposition with \(\Ind (p)\). By the Yoneda lemma there is an equivalence \(K^{\perp } \simeq \Ind (C)\) under which \(L\) corresponds to \(\Ind (p)\). Hence \(\Ind (A) \to \Ind (B) \to \Ind (C)\) is a localization sequence. Since \(\Ind (i)\) preserves compact objects, its right adjoint preserves filtered colimits, hence all colimits; so the sequence is strongly continuous by Lemma 2.13.

(2) Put \(A = K^{\omega }\) and \(B = D^{\omega }\). By Lemma 2.15, \(i\) restricts to a fully faithful functor \(A \to B\) whose image \(A = K \cap B\) is a thick subcategory of \(B\). By Lemma 2.2, the sequence \(A \to B \to (B/A)^{\idem }\) is short exact, so by (1) we obtain a localization sequence \(\Ind (A) \to \Ind (B) \to \Ind ((B/A)^{\idem })\). As \(K \simeq \Ind (A)\) and \(D \simeq \Ind (B)\), both \(E\) and \(\Ind ((B/A)^{\idem })\) are identified with \(K^{\perp }\) compatibly with the functors from \(D\), by Proposition 2.12(2). Hence \(E \simeq \Ind ((B/A)^{\idem })\) is compactly generated with \(E^{\omega } \simeq (B/A)^{\idem }\), and the claim follows. □

The distinctions can now be summarized as follows. In the first three rows, the first functor identifies the left-hand category with the kernel of the second.

NotionQuotient condition
Verdier sequence\(A,B,C\) are small stable categories and \(B/A \simeq C\).
Short exact sequence\(A,B,C\) are small idempotent complete stable categories and \((B/A)^{\idem } \simeq C\).
Localization sequence in \(\PrL _{\st }\)\(K,D,E\) are presentable stable categories and \(D/K \simeq E\); the right adjoint of \(D \to E\) is fully faithful.
Homological epimorphismAn exact functor \(A \to B\) in \(\Cat _{\perf }\) for which \(\Ind (A) \to \Ind (B)\) is a localization; no compact-generation condition on its kernel is imposed.

Passing through \(\Ind \) turns a short exact sequence into a localization sequence. For a localization between compactly generated categories, going back to a short exact sequence of compact objects requires the kernel to be compactly generated as in Theorem 2.17; strong continuity alone does not supply that hypothesis.

In the language of Definition 2.16: a functor \(f\colon A \to B\) in \(\Cat _{\perf }\) is a homological epimorphism if and only if \(\ker (\Ind (f)) \to \Ind (A) \to \Ind (B)\) is a strongly continuous localization sequence, and it is a Karoubi projection if and only if moreover \(\ker (\Ind (f))\) is compactly generated by objects of \(A\). In general, the kernel of a homological epimorphism need not be compactly generated, see Example 2.20 below; it is, however, always a dualizable category (Chapter 3).

Theorem 2.17 gives a description of idempotent complete quotients in terms of large categories. Recall from Corollary A.31 that \(\Ind (B) \simeq \Fun ^{\ex }(B\catop ,\Sp )\) for \(B \in \Cat _{\perf }\).

Corollary 2.18. Let \(i\colon A \hookrightarrow B\) be a fully faithful functor in \(\Cat _{\perf }\). Under the identification \(\Ind (-) \simeq \Fun ^{\ex }((-)\catop ,\Sp )\), the right adjoint \(\Ind (i)^R\colon \Ind (B) \to \Ind (A)\) is given by restriction along \(i\), and \[ (B/A)^{\idem } \simeq \ker \big (\Ind (i)^R\big )^{\omega }, \] where \(\ker (\Ind (i)^R) \subseteq \Fun ^{\ex }(B\catop ,\Sp )\) is the full subcategory of exact functors vanishing on \(A\). For the description of exact presheaves on \(B/A\) by this vanishing condition, see [SCT, Corollary 19.6.8].

Proof.

For \(a \in A\) and \(F \in \Ind (B)\) we have \(\hom _{\Ind (A)}(a,\Ind (i)^RF) \simeq \hom _{\Ind (B)}(ia,F) \simeq F(ia)\) by the Yoneda lemma, so \(\Ind (i)^R(F) \simeq F \circ i\catop \). Since \(A\) is idempotent complete and \(i\) is fully faithful, the essential image of \(i\) is a thick subcategory, so \(A \to B \to (B/A)^{\idem }\) is short exact by Lemma 2.2. By Theorem 2.17(1), \(\Ind (A) \to \Ind (B) \to \Ind ((B/A)^{\idem })\) is a localization sequence, so by Proposition 2.12(2) we have \(\Ind ((B/A)^{\idem }) \simeq \Ind (A)^{\perp }\). Finally, \(F \in \Ind (A)^{\perp }\) if and only if \(\hom (a,\Ind (i)^RF) \simeq \hom (ia,F) \simeq 0\) for all \(a \in A\), if and only if \(\Ind (i)^RF \simeq 0\). Taking compact objects gives the claim. □

Remark 2.19. The functor \(\Ind \) induces an equivalence of categories \[ \Ind \colon \Cat _{\perf } \rightleftarrows \PrL _{\omega ,\st }\noloc (-)^{\omega }, \] where \(\PrL _{\omega ,\st }\) denotes the category of compactly generated presentable stable categories and colimit-preserving functors that preserve compact objects (equivalently, strongly continuous functors), see Theorem A.17 and Lemma 2.14. For a functor \(f\colon A \to B\) in \(\Cat _{\perf }\):

  • \(f\) is fully faithful if and only if \(\Ind (f)\) is fully faithful (by the formula for mapping spaces in Construction A.21), if and only if \(\Ind (f)\) is a monomorphism [Efimov (2024), Proposition 1.13];
  • If \(f\) is a Karoubi projection, then \(\Ind (f)\) is a localization (Theorem 2.17), or equivalently \(\Ind (f)\) is an epimorphism [Efimov (2024), Proposition 1.13]. The converse does not hold, see Example 2.20.

Example 2.20 (Keller, [Keller (1994)]). Let \(A\) be a ring and let \(0 \neq I \subseteq \mathrm {Jac}(A)\) be a Tor-unital ideal. Then \(A/I \otimes ^L_A A/I \simeq A/I\), so the restriction functor \(\Mod _{A/I} \to \Mod _A\) is fully faithful and \(f\colon \Perf _A \to \Perf _{A/I}\) is a homological epimorphism. The category \[ \ker (\Mod _A \to \Mod _{A/I}) \] contains no nonzero compact objects. Note that \(\Mod _A \simeq \Ind (\Perf _A)\) and \(\Mod _{A/I} \simeq \Ind (\Perf _{A/I})\). So the kernel of \(f\) is zero, whereas the large kernel contains the nonzero module \(I\), since \((A/I) \otimes _A^L I \simeq 0\). This gives a counterexample to the converse of the second statement of Remark 2.19: \(\Ind (f)\) is a localization, but \(f\) is not a Karoubi projection.

For example, consider \(A = k[t,t^{1/2},t^{1/4}, \dots ]_{(t,t^{1/2}, t^{1/4}, \dots )}\), for \(k\) a field. Let \(\mm \) be the maximal ideal. Then the map \(A \to A/\mm \) is an example.
