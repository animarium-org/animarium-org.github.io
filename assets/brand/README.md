# Animarium brand assets

The mark is a slim capital A whose crossbar is an equals sign, representing an
identification in synthetic category theory.

The site assets use the colours from the shared reader stylesheet. The lockup
switches with the page's light or dark colour scheme. Its outlined wordmark and
mark are taken from the original assets below.

| File | Use |
|---|---|
| `site-lockup.svg` | Site header in light and dark modes |
| `site-favicon.svg`, `site-favicon-32.png` | Browser tab icon |
| `site-apple-touch-icon.png` | 180 px icon for phones |
| `site-github-avatar.png` | 500 px avatar for the animarium-org GitHub organization |

The original brand assets use ink `#1E2A3F`, ochre `#B5651D`, and paper
`#FBFAF7`. The ochre on the dark tile is `#D88A45`.

| File | Use |
|---|---|
| `animarium-mark.svg` | the mark on light backgrounds |
| `animarium-mark-light.svg` | the mark on dark backgrounds |
| `animarium-lockup.svg` | mark and wordmark, for the site header |
| `animarium-lockup-light.svg` | the same on dark backgrounds |
| `favicon.svg`, `favicon-32.png` | browser tab icon (dark tile) |
| `apple-touch-icon.png` | 180 px icon for phones |
| `github-avatar.png` | 500 px avatar for the animarium-org GitHub organization |

The wordmark is EB Garamond (weight 500) converted to outlines, so the SVGs need no
fonts. EB Garamond is licensed under the SIL Open Font License; the site may also load
it as a web font for headings.

Use these links on the main site pages.

```html
<link rel="icon" href="/assets/brand/site-favicon-32.png" sizes="32x32" type="image/png">
<link rel="icon" href="/assets/brand/site-favicon.svg" sizes="any" type="image/svg+xml">
<link rel="apple-touch-icon" href="/assets/brand/site-apple-touch-icon.png">
```
