Corollary 5.76.

Let \(q\colon T\to S\) be a quotient of logoi. For an acyclic class \(L\) in \(T\), write \(q_!L\) for the acyclic class generated by \(q(L)\) in \(S\). Then \(q_!(L\cdot M)=q_!L\cdot q_!M\) for any two acyclic classes \(L\) and \(M\) in \(T\).

Proof
The inverse image of an acyclic class under \(q\) is acyclic, since \(q\) preserves colimits and pullbacks. Thus taking the acyclic closure before applying \(q\) gives the same generated class in \(S\). Since \(q\) preserves products and pushouts, \(q(u\ssquare v)\simeq q(u)\ssquare q(v)\). By Lemma 5.75, these maps generate both sides as \(u\) runs through \(L\) and \(v\) through \(M\).
